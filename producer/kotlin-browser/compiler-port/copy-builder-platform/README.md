# Selected CopyBuilder platform bounds

The original Java descriptor contracts have unannotated type-parameter and
wildcard upper bounds. The selected genuine ErrorFunctionDescriptor uses
CopyBuilder<SimpleFunctionDescriptor?>. This unit preserves that original
nullable argument and the nonnull builder object result while retaining build's
nullable result. It changes six exact metadata spans in four generated contracts;
no builder implementation body changes.

Preparation verifies and preserves the full descriptor-signatures predecessor,
including its three complete predecessor replays. Three replacements belong to
descriptorPlatformSignaturesReceipt; PropertyDescriptor belongs to the genuine
descriptorReceipt. The property source is bound to that verified complete
descriptor receipt. A final verifier checks all four actual owner filenames,
algorithm bytes and allowed assembly imports before returning a precise
predecessor source view for the unchanged signature final verifier. Every other
actual final input remains in that view.

The selected declaration/caller guard records nine actual contract files and the
23 nullable ErrorFunctionDescriptor builder types. It also verifies the completed
3,521-source whole-build graph by its actual compiler argument filenames and
source hashes. This is conservative lexical evidence; arbitrary aliases,
inheritance, reflection and string interpolation remain outside it.

[Sealed evidence](evidence/differential.json) preserves 1,731 raw JVM observations
with exact original/common equality. All 27 original Java interfaces are rebuilt;
the four complete common interfaces and the complete selected shipping
ErrorFunctionDescriptor also compile. The latter is compiled against the original
Java family, then its unchanged builder bodies execute against either that family
or the four complete common replacements. Verified bootstrap Function and
Property copy configurations provide genuine nonnull receiver observations.
The bootstrap artifact's source commit is unknown. This is a selected JVM ABI
boundary, not a complete common descriptor runtime or a Wasm result.

The actual nullable typed observer fails before with four bound errors and
compiles after. A retained 39-source complete generated-family typecheck still
fails: its errors fall from 30 to seven, removing precisely the 23 builder bound
errors. The IR getter, native superclass and collection override failures remain
in the evidence. No fixture descriptor or stub superclass hides them.

Five integrity tests preserve the exact six spans and reject unrecorded builder
types/aliases. The public final verifiers accept all four actual files after
in-place assembly imports and the exact 11-file signature predecessor view. They
reject a body change with unchanged generic inventory, a duplicate import and
identical bytes from the wrong filename. Old predecessor files stay unchanged.
The two initial observer/tool failures and their artifacts/logs are preserved.

The preparer requires the genuine verified signature component and actual selected
Kotlin pins. Call `verifyCopyBuilderPlatform(outputRoot)` before assembly. After
assembly, call `verifyFinalCopyBuilderPlatform` with the actual selected map and
vetted added imports, then pass only its `predecessorRetainedSources` to the
unchanged signature final verifier. Other final guards continue to use the actual
map.

For a prepared component, run `node probe.mjs --runtime <new-out-root>
<prepared-root>`. Set `COPY_BUILDER_PREPARATION=<prepared-root>` when running
`node --test prepare.test.mjs`; setting `COPY_BUILDER_FINAL_OUTPUT=<new-out-root>`
also runs the actual copied-profile final assembly and rejection guards.
Full descriptor-family runtime, Wasm execution, a complete compiler build and
public language readiness remain false.
