This component ports the complete pinned `AbstractReceiverParameterDescriptor`,
`ReceiverParameterDescriptorImpl`, `AbstractReceiverValue`, `ExtensionReceiver`,
`TransientReceiver`, and `DescriptorFactory` Java implementations into common
Kotlin. It adds six source files. It keeps all factory overloads and algorithms,
including getter/setter creation, object constructors, enum methods and entries,
and callable/class context receivers. No retained Kotlin consumer is replaced.

The receiver substitution preserves the class-owned `OUT_VARIANCE` branch, the
callable-owned invariant branch, null substitution, reference-identity reuse,
fresh transient values, original links, and copy semantics (including the
original custom-name reset). The receiver setter remains virtual and uses the
producer's enabled-assertion policy. `ReceiverValue` and descriptor contracts,
the genuine descriptor bases, and the complete function implementations are
bound by canonical bodies, selected owners, predecessor receipts, and their
source locks. The ninth bound dependency file is the generated `TypeProperties`
alias artifact used by the retained context receivers' `.original` getters.
Reference snapshots include the complete original factory and its
five unported Java property/constructor dependencies.

`prepareDescriptorReceiverFactory` belongs after function implementation
preparation and before global property-import assembly. It receives the actual
selected source rows and `preparedDescriptorFunctions`, `preparedDescriptorBases`,
`preparedTypeContracts`, and `preparedDescriptorContracts`. The latter two use
their returned nested output roots. `verifyDescriptorReceiverFactory` and the
final verifier require the external preparation receipt SHA. The final verifier
checks the actual six selected outputs, exact canonical body or recorded import
assembly, dependency/consumer owners and bodies, duplicate paths/owners, original
Java reintroduction, and extra component outputs. It removes exactly the six
verified outputs from the view returned to the older function/base guards.

The JVM proof rebuilds the six original Java implementations, the original
function/base family, genuine context receiver Kotlin consumers, all generated
descriptor contracts, and the common six implementations. The same Java
observer then compares raw records for substitution variance, identity and copy
behavior, visitors, assertion failures and valid type updates, public setter
override dispatch, all factory overloads, null receiver creation, context labels,
enum predicates, and enum entries. The bootstrap builtins module has no
`EnumEntries`, so the default and missing-finder cases return null. The positive
factory case supplies the genuine builtins `Array` descriptor through the
original configurable `StdlibClassFinder` capability; it checks the complete
factory path with a real one-parameter class, not stdlib discovery of
`EnumEntries` itself.

The actual selection guard proof binds the immutable failed whole invocation
and its argument-file SHA, adds six sources to its 3,522 selected Kotlin files,
and passes the existing function final verifier after reversing this component.
The separate early positive is a boundary model: it privately copies canonical
genuine dependency and consumer files and unchanged predecessor receipts, then
verifies preparation with no assembly imports. It does not claim fresh public
predecessor preparation or a full early whole invocation. Adversarial cases
include rehashed algorithm/dependency changes, missing/duplicate/switched owners,
receipt mutation, duplicate/unrecorded imports, original Java reintroduction,
extra outputs, output reuse, and source/output overlap. Restored positives pass.

`PropertyAccessorDescriptorImpl`, `PropertyGetterDescriptorImpl`,
`PropertySetterDescriptorImpl`, `PropertyDescriptorImpl`, and
`ClassConstructorDescriptorImpl` remain genuine bootstrap dependencies in the
focused JVM proof and still need common implementation ports for the whole
compiler. The proof also uses the genuine type system, builtins, descriptor
substitutor, and storage bootstrap dependencies. Java platform-null construction,
raw reflection/binary shape, arbitrary Java collection mutation, and assertion-
disabled runs are not parity claims. Complete common classes have not executed
on Wasm; this component does not claim a compiler binary or browser readiness.

Run the focused proof with `node probe.mjs <fresh repository out/ directory>`.
Run the selection and negative guards with `node --test prepare.test.mjs`.
Completed runtime, integrity, and execution evidence is sealed under `evidence/`.

The runtime proof compiled this same alias artifact before the final guard added
its explicit ninth predecessor binding. Its original eight-binding source lock
is archived with its exact executed-input SHA; shipping classes and runtime
probe are unchanged. The selection proofs use the final nine-binding lock.
